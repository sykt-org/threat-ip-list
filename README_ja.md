# Threat IP List
SYKTが設置しているハニーポットや、公開されているプロキシをブロックするシステムにより集められたIPアドレスをまとめて公開しているレポジトリです。<br>
なるべく正確な情報が提供できるよう最善を尽くしますが、**時には誤った情報を提供するかもしれませんし、完璧ではありません**。<br>
本リストをご利用の際は過信せず、あくまでも判断材料の1つに留めることを推奨します。

もし気に入っていただけましたら、任意ではありますがスターやクレジット表記などをいただけると嬉しいです。

## 取得方法
```
https://raw.githubusercontent.com/sykt-org/threat-ip-list/main/list/ips.txt
```
改行で区切って使用できます。

## 更新頻度
原則10分に1回の頻度で更新しますが、変更が無ければ更新は行いません。

## 削除について
過去92日間不審なアクティビティが検出されなければ、そのIPアドレスは自動的に削除されます。<br>
もしも登録に何らかの誤りがあるとお考えの場合は、 `siyukatu@gmail.com` までご連絡ください。<br>
なお、IPアドレスを実際にご利用中の方のみを受け付けます。
