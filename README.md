# Threat IP List
This repository provides a compiled list of IP addresses collected through honeypots set up by SYKT and a system that blocks public proxies.<br>
We do our best to provide information that is as accurate as possible, but **it may sometimes provide incorrect information and is not perfect**.<br>
When using this list, we recommend not relying on it excessively and using it merely as one of many factors for your judgment.

If you like it, we would appreciate it if you could give us a star or include credits, although it is entirely optional.

## How to Get the List
```
https://raw.githubusercontent.com/sykt-org/threat-ip-list/main/list/ips.txt
```
You can use it separated by line breaks.

## Update Frequency
As a general rule, it is updated once every 10 minutes, but if there are no changes, no update will be performed.

## About Removal
If no suspicious activity is detected for the past 92 days, the IP address will be automatically removed.<br>
If you believe there is any error in the registration, please contact us at `siyukatu@gmail.com`.<br>
Please note that we only accept requests from people who are currently using the IP address in question.
